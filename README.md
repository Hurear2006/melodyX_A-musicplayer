# 🎵 MelodyX — Responsive Music Website

🎧 **MelodyX** is a modern, responsive music website designed to provide a clean and simple interface for discovering and listening to songs. The project combines an elegant visual design with an intuitive music-player experience.

## ✨ Project Overview

MelodyX presents a web-based music player where users can browse songs, view album artwork, see song and artist information, and control playback through an easy-to-use interface.

The website also includes dedicated **About** and **Contact** sections, making it a complete front-end music platform concept.

## 🚀 Features

- 📱 Responsive and modern website layout
- 🎨 Clean and minimal user interface
- 🎵 Built-in music player
- ▶️ Play and pause controls
- ⏮️ Previous and next song controls
- 📊 Music progress/seek bar
- ⏱️ Current playback time and total duration
- 🎶 Dynamic song information
- 🖼️ Album/song artwork display
- 🎼 Multiple songs available in the playlist
- 🧭 Easy navigation between Home, About, and Contact sections
- 📖 About section with project information and features
- 📩 Contact section with:
  - 👤 Name field
  - 📧 Email field
  - 💬 Message field
  - 🔗 Contact/social links
- 💻 Responsive experience across different screen sizes

## 🎧 Music Player

The main music player displays:

- 🖼️ Song cover artwork

- 📊 Playback progress
- ⏱️ Current time
- 🕒 Total duration
- ⏮️ Previous button
- ▶️ Play/Pause button

## 🌐 Website Sections

### 🏠 Home

The **Home** section provides the main music-player experience, allowing users to view the currently selected song and control playback.

### 📖 About

The **About** section introduces MelodyX and explains its purpose, features, user experience, responsive design, and overall mission.

### 📩 Contact

The **Contact** section provides a simple form where visitors can enter their name, email address, and message.
